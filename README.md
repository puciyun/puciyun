# Puciyun Technology Website

Complete enterprise website for Sichuan Puciyun Technology Co., Ltd, designed for global markets with full English support.

## Project Structure

```
puciyun/
├── index.html                 # Homepage
├── css/
│   └── style.css             # Main stylesheet with animations and responsive design
├── js/
│   ├── main.js               # Core functionality (navigation, forms, interactions)
│   └── animations.js         # Advanced animations and effects
├── images/
│   ├── favicon.svg           # Website favicon
│   ├── logo.svg              # Company logo
│   └── [other media files]
├── pages/
│   ├── services.html         # Services page
│   ├── culture.html          # Company culture page
│   ├── news.html             # Company news page
│   ├── contact.html          # Contact page
│   ├── careers.html          # Careers page
│   ├── privacy.html          # Privacy Policy
│   ├── terms.html            # Terms of Service
│   └── cookies.html          # Cookie Policy
├── robots.txt                # SEO - Search engine directives
├── sitemap.xml               # XML sitemap for search engines
└── app-ads.txt               # App advertising configuration

```

## Features

### Pages
- **Homepage (index.html)**: Hero section, services overview, mobile apps showcase, statistics, call-to-action
- **Services (services.html)**: Detailed service descriptions with 6+ service categories
- **Culture (culture.html)**: Mission, vision, core values, company story, team, certifications
- **News (news.html)**: Company announcements, industry news, newsletter subscription
- **Contact (contact.html)**: Contact form, office information, support details
- **Careers (careers.html)**: Job listings, benefits, application process
- **Legal Pages**: Complete Privacy Policy, Terms of Service, Cookie Policy with global compliance

## Installation

1. Extract files to your web server root directory
2. Ensure all directories (css/, js/, images/, pages/) are created
3. Upload all files maintaining the directory structure
4. Configure domain DNS to point to your server
5. Update email addresses in contact forms
6. Set up SSL certificate for HTTPS
